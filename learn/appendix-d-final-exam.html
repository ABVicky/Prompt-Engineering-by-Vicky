🎓 Appendix D: Final Exam

40 multiple-choice questions + 5 practical tasks covering all 18 modules. Passing score: 32/40 (80%). Time yourself: 60 minutes for the MCQs. Answers and explanations are hidden at the end of each section.

👔 Non-Tech Track Focus: Questions 1–20 (Foundations & Core Techniques), Questions 31–40 (Domains, Safety & Evaluation), and Practical Tasks 1 & 4. 💻 Tech Track Focus: All 40 questions (including structured JSON, function calling, RAG architectures, and PromptOps) and all 5 practical tasks.

Part 1 — Foundations (Modules 01–04)

1. During pre-training, an LLM learns to: A) Retrieve facts from a database B) Predict the next token C) Follow user instructions D) Execute code

2. Roughly how many tokens are in 300 English words? A) 100 B) 225 C) 400 D) 1,200

3. For consistent data extraction, the best temperature is: A) 0–0.3 B) 0.7 C) 1.0 D) 1.5

4. Why do LLMs struggle to count letters in a word? A) They see tokens, not characters B) No math ability C) Temperature too high D) Context window too small

5. Which prompt block most often has the biggest impact? A) Role B) Context C) Emoji D) Sign-off

6. What's the main purpose of delimiters like <document> tags? A) Decoration B) Reduce tokens C) Separate instructions from data D) Increase temperature

7. "Don't use jargon" is weaker than "Use everyday words" because: A) It's longer B) Models ignore the word "don't" entirely C) It uses more tokens D) Negative instructions don't specify the desired behavior

8. Few-shot examples should be: A) Diverse, correct and representative B) Identical in structure and topic C) All edge cases D) As long as possible

9. Prefilling the assistant's response with { mainly helps to: A) Increase creativity B) Force JSON output to start immediately C) Lower cost D) Avoid tool calls

10. "You are the world's greatest physicist" primarily: A) Adds physics knowledge B) Guarantees accuracy C) May shift tone, but adds no knowledge D) Disables hallucinations

1-B · 2-C (300 × 1.33 ≈ 400) · 3-A · 4-A · 5-B · 6-C · 7-D · 8-A · 9-B · 10-C

Part 2 — Intermediate (Modules 05–09)

11. Chain-of-thought reasoning should be placed: A) After the answer B) In the system prompt only C) It doesn't matter D) Before the answer

12. Self-consistency requires: A) Multiple samples and a vote B) Temperature 0 and one sample C) A vector database D) Fine-tuning

13. Step-back prompting means: A) Undoing the previous message B) Asking a general principle question first C) Reducing temperature D) Removing examples

14. With reasoning ("thinking") models, you should usually: A) Add "think step by step" everywhere B) Use temperature 2 C) Give goals, constraints and success criteria D) Provide 50 examples

16. Why place an "evidence" field before "label" in a JSON schema? A) The label is then conditioned on evidence B) Alphabetical order C) Parsers require it D) It reduces tokens

17. Where should rules that apply to every turn of a chatbot go? A) The user message B) The system prompt C) The assistant prefill D) A stop sequence

18. Which pattern classifies inputs and sends them to specialized prompts? A) Evaluator-optimizer B) Self-consistency C) Routing D) Prefill

19. For long documents, place the question: A) Before the document B) In the middle C) In a separate API call only D) After the document

Part 3 — Advanced (Modules 10–14)

24. MCP standardizes: A) How apps expose tools/resources/prompts to LLM clients B) Tokenization C) Image generation D) Model training

Part 5 — Practical Tasks (graded by rubric)

P1. Prompt makeover (Modules 02–04). Rewrite "write about our new app" into a complete prompt for a launch email.

P2. Extraction (Module 06). Write a prompt + JSON schema to extract event details (name, date, venue, price, organizer) from posters' text, with null handling.

P3. System prompt (Module 07). Write a system prompt for a college-admissions FAQ bot with escalation rules.

P4. Evaluation (Module 13). Design 10 test cases and the grading method for P2.

P5. Security (Module 14). Threat-model an assistant that reads a user's inbox and drafts replies. List 5 mitigations.

P5 reference mitigations: treat email bodies as untrusted data; drafts only, never auto-send (a human approves each one); no access to unrelated tools; don't render external images/links in drafts; log and flag emails containing instruction-like text; redact sensitive data in logs.
