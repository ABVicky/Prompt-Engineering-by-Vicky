🩺 Appendix F: Troubleshooting

Symptom → likely cause → fix. Find your problem, apply the fix, re-test.

📝 Output Quality

SymptomLikely causeFix
Generic, bland answerMissing context, audience, purposeAdd who/why/constraints; give an example
Too longNo length limit; verbose examples"Max 100 words / 3 bullets"; shorter examples; lower max_tokens
Too short / superficialNo depth requested"Detailed, with examples and edge cases"; ask for sections
Wrong toneTone not specified or prompt style mismatchedDescribe tone with contrasts; give a sample; write the prompt in that tone
"AI-sounding" clichésDefault styleBan specific phrases; give voice samples
Repetitive phrasingLong generation, low diversityRaise temperature slightly; frequency penalty; ask for varied structure
Starts with "Sure! Here's…"No format constraint"Begin directly with…"; prefill; strip in code
Ignores one instructionToo many rules; buried instructionNumber & prioritize rules; put critical ones at the end; split into a chain
Follows examples too literallyExamples too similarDiversify; "examples show format only"
Different answer every timeTemperature too high; ambiguous promptLower temperature; more specific prompt; structured output
Agrees with my wrong assumptionLeading question / sycophancyAsk neutrally; request critique and counterarguments
Refuses a legitimate requestAmbiguous intent; missing contextExplain the legitimate purpose and context; rephrase neutrally

🧠 Accuracy & Reasoning

SymptomLikely causeFix
Made-up facts / citationsNo grounding; pressure to answerProvide sources; allow "I don't know"; quote-first; verify citations
Wrong mathMental arithmeticStep-by-step; code execution / calculator tool
Wrong multi-step logicNo thinking roomCoT; decomposition; reasoning model
Outdated infoKnowledge cutoffProvide current data; search tool; include today's date
Misread a long documentLost in the middle; question placed firstDocs first, question last; quote extraction; RAG
Confuses multiple documentsNo labelsWrap each in tags with source/index metadata

🧱 Format & Parsing

SymptomLikely causeFix
Invalid JSONFree-form generationStructured outputs / tool schema; prefill {; validate & retry
JSON wrapped in code fencesDefault markdown habit"Raw JSON only"; strip fences in code
Wrong labels ("Positive" vs "positive")No enumEnums in schema; exact label list; normalize in code
Cut off mid-sentencemax_tokens reachedRaise limit; check stop_reason; ask for shorter output
Markdown appears in plain-text UIPrompt written in markdown"Plain text only"; write prompt in prose; strip in code

🔗 RAG & Agents

SymptomLikely causeFix
"I don't know" though answer existsRetrieval missLog retrieved chunks; hybrid search; query rewrite; bigger k; better chunking
Answers from outside knowledgeWeak grounding"Only use documents"; quote-first; lower temperature
Agent loops foreverNo stopping ruleMax steps; clear done criteria; detect repeated calls
Wrong tool chosenVague tool descriptions; overlapping toolsClarify "use when / not when"; merge tools
Bad tool argumentsUnclear parameter docsDescribe formats with examples; enums; return helpful errors
Agent followed instructions from a web pageIndirect injectionUntrusted-data labels; least privilege; approvals; quarantine pattern

⚙️ API & Operations

SymptomLikely causeFix
401/403Bad key / permissionsCheck env var, key scope, org/project
400Invalid parameters / too longRead error message; check model name, token limits, message format
429Rate limitBackoff with jitter; request limit increase; batch
5xx / overloadedProvider issueRetry; fallback model/provider
Slow responsesLong outputs; big model; long promptsStream; smaller model; shorter output; caching; parallelize
Costs explodingLong histories; big model everywhere; verbose outputsSummarize history; route to smaller models; cache; cap output
Quality dropped after model updateModel behavior changedRun eval suite; adapt prompt; pin model versions

🧭 Universal Debugging Procedure

  1. Reproduce with the exact prompt, model and parameters (check your logs).
  2. Isolate — is it the prompt, the context/data, the model, or your code?
  3. Ask the model: "Which part of my instructions was unclear or conflicting?"
  4. Change one thing, re-run on the full test set.
  5. Add the case to your eval set so it never regresses.
